🚀 Guide Complet d'Utilisation

Découvrez comment utiliser toutes les fonctionnalités de Sarbi Rohek

🔐 Étape 1 : Authentification

Toutes les fonctionnalités nécessitent une authentification (sauf la page d'accueil).

  • Créer un compte

    Allez sur la page d'inscription et créez votre compte en tant que client ou prestataire.

  • Se connecter

    Utilisez vos identifiants sur la page de connexion.

  • Accéder à votre espace

    Après connexion, vous serez redirigé vers votre espace personnel (client-space ou provider-space).

👤 Espace Client

Une fois connecté, accédez à votre espace client pour gérer vos commandes et découvrir des prestataires.

📖 Annuaire

Découvrez tous les prestataires disponibles, filtrez par catégorie, note et prix.

💬 Messages

Communiquez directement avec les prestataires en temps réel.

📊 Dashboard

Visualisez vos statistiques, demandes actives et dépenses totales.

❤️ Favoris

Sauvegardez vos prestataires préférés pour les retrouver facilement.

💳 Paiements

Consultez votre historique de paiements et transactions.

🔔 Notifications

Recevez des alertes pour les nouveaux messages et mises à jour.

  • Consulter le profil des prestataires

    Cliquez "Voir plus" sur une fiche pour consulter le portfolio et les avis.

  • Envoyer un message

    Cliquez le bouton Message pour discuter directement avec un prestataire.

  • Créer un devis

    Allez dans "Mes devis" pour demander un devis détaillé à un prestataire.

  • Publier un avis

    Partagez votre expérience en publiant un avis sur un prestataire.

🔧 Dépannage

❌ Message "Connexion requise"

Vous devez d'abord vous connecter pour accéder aux fonctionnalités. Allez sur la page de connexion.

❌ Les données ne se chargent pas

Assurez-vous que vous êtes connecté. Rafraîchissez la page (F5) ou fermez/réouvrez votre navigateur.

❌ Erreur sesession expirée

Votre session a expiré. Reconnectez-vous pour continuer.

✅ Conseil: Les meilleures performances sont obtenues avec les derniers navigateurs (Chrome, Firefox, Safari, Edge).

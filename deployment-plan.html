4. Deployment Architecture

Comment l'app est distribuée entre les services

Stack Technologique - Sarbi Rohek

Votre application utilisera cette architecture

Service Ce qu'il héberge Plateforme Pourquoi ce choix?
Frontend React / HTML + CSS + JS
(pages client-space, provider-space, etc.)		 Vercel Déploiement auto depuis GitHub, CDN intégré, SSL gratuit
Backend Java Spring Boot / Tomcat
(AdminAccountsServlet, ProvidersSearchServlet, etc.)		 Scaleway / OVH VPS Haute perf Java, gestion mémoire, support long-term
Database MySQL 8
(Tables: users, providers, reviews, etc.)		 Local ou Managed Compatible avec votre architecture existante
Cache Données fréquemment consultées
(Providers, Favorites, Reviews)		 Redis 3x plus rapide que MySQL seul, simple intégration
AI/Moderation OllamaModerationService
(Modération contenu)		 Local ou API externe Processus d'arrière-plan, pas besoin haute dispo immédiate

Communication entre services

→ User ouvre app → Browser charge depuis Vercel (Frontend React)
→ User se connecte → Frontend appelle LoginVerificationServlet
→ Backend vérifie credentials → Quête MySQL table users
→ Résultats mis en cache → Redis 1h TTL
→ User browse providers → Frontend appelle AllProvidersServlet
→ Cache hit → Redis retourne résultat (< 10ms)
→ User ajoute review → OllamaModerationService vérifie contenu
→ Si OK, sauvegardé → Database + cache invalidé

Deployment order (faire dans cet ordre)

1
Préparer le serveur (OVH ou Scaleway)
• Créer compte OVH/Scaleway
• Commander VPS (Ubuntu 22.04)
• Installer Java 17, Tomcat 10, MySQL 8
• Ouvrir ports 8080 (Tomcat), 3306 (MySQL), 443 (HTTPS)
2
Déployer backend Java + Servlets
• Compiler AdminAccountsServlet.java, etc.
• Créer WAR file
• Déployer dans /tomcat/webapps/sarbi_rohek
• Tester AdminModerationServlet, LoginVerificationServlet
• Configurer réplication MySQL (si Managed)
3
Connecter base de données
• Créer utilisateur MySQL: sarbi_user@localhost identified by 'XXXXX'
• Importer schéma (structure tables)
• Vérifier accès Tomcat → MySQL
• Tester queries AdminAccountsServlet
4
Ajouter Redis Cache (optionnel mais recommandé)
• Installer Redis: sudo apt install redis-server
• Configurer Jedis client dans pom.xml
• Implémenter cache pour AllProvidersServlet, FavoritesServlet
• Set TTL 1h pour données fréquentes
5
Déployer frontend React / Vercel
• Créer repo GitHub sarbi-frontend
• Connecter Vercel à GitHub
• Set variables d'env: REACT_APP_BACKEND_URL = monserveur.com:8080
• Vercel auto-déploie à chaque push
• Frontend accessible partout avec SSL gratuit
6
Configurer monitoring et sécurité
• Uptime Robot: tracker santé backend
• Certbot SSL: sudo certbot certonly --standalone
• Configurer CORS Tomcat
• Tester logs access/errors Tomcat
• Sauvegarder DB quotidien (cron job)
